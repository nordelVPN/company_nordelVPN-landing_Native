# Документация NordelVPN Landing (`company_nordel-landing_Native`)

> **Единый стандарт экосистемы (приоритет):** функциональные требования, языки, состав страниц, валюта, Telegram-вишлист и общие стандарты платформы зафиксированы в [общей документации VPN_commerce](../../docs/README.md). Этот проект отличается от остальных лендингов экосистемы **только внешним видом (дизайном, палитрой, брендом NordelVPN)** и назначенной тарифной сеткой.

## Профиль проекта по единому стандарту

- **Роль:** базовый лендинг-эталон экосистемы `VPN_commerce`.
- **Тарифная сетка:** **Сетка A** (общая с LuniVPN), основная валюта — **EUR (`€`)**:
  - `Trial` — 5 дней · `€0.50` · 10 устройств · Все возможности
  - `Basic` — 1 месяц · `€7` · 5 устройств · 3 сервера
  - `Plus` — 6 месяцев · `€25` · 5 устройств · Все серверы + расширение браузера
  - `Complete` — 12 месяцев · `€55` · 10 устройств · Все серверы + расширенные + блокировщик рекламы + менеджер паролей + облако данных
- **Целевые языки (единые для всех 4 сайтов, 12 языков):** `en` (по умолчанию), `pl`, `uk`, `lt`, `tr`, `ro`, `de`, `sk`, `hr`, `sr`, `bg`, `hu` (см. [единый контракт i18n](../../docs/architecture/i18n.md)).
- **Целевой состав страниц (единый для всех 4 сайтов):** основной лендинг (`index.html` + Telegram-вишлист на PHP 8.4), регистрация (`create-account.html`), вход в аккаунт (`login.html`), восстановление пароля (`forgot-password.html`), личный кабинет (`account.html`). Подробнее — [единый состав страниц](../../docs/product/pages-and-flows.md).
- **Уникальное для бренда:** светлая и тёмная темы (`nordel-theme`), дизайн-концепты NordelVPN и локальные QA-проверки.
